# Sistema de productos

Aplicación web desarrollada con Django para registrar y listar productos almacenados en una base de datos.

## Tecnologías
- Python
- Django
- SQLite
- HTML
- Git y GitHub

## Ejecución
1. Crear el entorno virtual.
2. Instalar Django.
3. Ejecutar las migraciones: `python manage.py migrate`
4. Ejecutar el servidor: `python manage.py runserver`
